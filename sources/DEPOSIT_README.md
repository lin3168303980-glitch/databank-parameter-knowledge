# DataBank 竞品公域参数沉淀

## 范围

从292份有效模型中筛出95条竞品相关公域池。CSV逐池保留字段路径、来源包名和人群ID、池序号、标准品牌代码、行为、日期、类目/末级类目、商品ID、扩展筛选和来源标签文件。`sources/`内有41个人群模型JSON及对应页面标签文本，按CSV的`index`字段关联。类目ID翻译表覆盖本批出现的36个唯一类目ID。

## 竞品行为模型

- 类目级：`selectionLv1=["COMMON_TOUCH","PUBLIC_CATE_BHV"]`。以`selectionLv3`中的类目、标准品牌、行为、日期和`extraFilters`限定条件定义人群。类目ID字段可能是`cate`或`leafCates`，以原始JSON为准。
- 单品级：`selectionLv1=["COMMON_TOUCH","PUBLIC_ITEM_BHV"]`。商品ID通过对应公域商品行为卡的`extraFilters.item`定义，以原始JSON为准。
- 店铺私域商品行为`COMMODITY/ITEM`不能代替竞品公域行为；`CROWD/CUSTOM`只是已保存人群引用，不等同于品牌/商品筛选代码。

## 已见行为代码

| 代码 | 留存含义 | 适用卡片 |
|---|---|---|
| `18919#|#CATE_PUBLIC_PAY` | 公域类目购买 | `PUBLIC_CATE_BHV` |
| `18930#|#CATE_PUBLIC_VIEWITEM` | 公域类目浏览 | `PUBLIC_CATE_BHV` |
| `19299#|#CATE_PUBLIC_PAY` | 公域单品购买 | `PUBLIC_ITEM_BHV` |

以每条记录的原始JSON为准，代码不能跨公域卡片错用。

## 品牌代码可信度

| stdBrand | 来源关联 | 状态 |
|---|---|---|
| `20034` | 雅诗兰黛 | 已有品牌实测记录，并在本批雅诗兰黛公域包中出现 |
| `20067` | 兰蔻 | 从兰蔻命名公域包关联，尚未由品牌选择器单独复核 |
| `20137` | 海蓝之谜 | 从海蓝之谜命名公域包关联，尚未由品牌选择器单独复核 |
| `18641319` | CPB候选关联 | 出现在CPB命名模型中，但界面品牌名未展开；标为待核实，不作为确认的竞品代码 |

不要根据人群包名称推断品牌代码。新增品牌时应从对应公域模型和页面标签读取真实的`stdBrand`、类目/商品ID和行为代码，再更新留存表。

`50011977`为洁面；`50011980`为乳液/面霜合并类目，不能仅凭该ID断言成单独面霜。其余中文映射和证据状态见`category-id-translations.csv`。
